## 四、复测中发现并修复的两个问题（可写进论文"问题排查"）

### 问题 1：rsync 报 `Host key verification failed`
- 现象：`/var/log/backup.log` 中 rsync 失败，`ssh -o BatchMode=yes root@192.168.10.10` 报错
- 原因：web1 的 `/root/.ssh/known_hosts` 中没有 lb-master 的主机密钥，SSH 默认拒绝首次连接
- 修复：`backup.sh` 中首次执行时用 `ssh-keyscan -t ed25519 192.168.10.10 >> /root/.ssh/known_hosts` 预置密钥
- 修复后：rsync 日志干净（`sent 1,596 bytes ... speedup is 3.69`），两端文件一致

### 问题 2：Zabbix Agent 采集不到数据（主机显示"未采集/不可用"）
- 现象：仪表盘长期存在 "Zabbix agent is not available" 告警，`agent.ping` 监控项 `lastclock=0`
- 原因：三台主机的 `/etc/zabbix/zabbix_agent2.conf` 仍是**默认值** `Server=127.0.0.1`、`ServerActive=127.0.0.1`、`Hostname=Zabbix server`，Zabbix Server 从 192.168.10.200 发起的被动检查被 Agent 拒绝
- 修复：改为 `Server=192.168.10.200`、`ServerActive=192.168.10.200`、`Hostname=<本机名>`，重启 `zabbix-agent2`
- 修复后：主机列表 ZBX 全绿，`agent.ping` 返回 `1`，告警自动消除
